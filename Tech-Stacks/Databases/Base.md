## So sánh PostgreSQL và MySQL
```bash
- PostgreSQL:
    "mạnh" ở khả năng xử lý dữ liệu phức tạp -> Đây là điểm quan trọng nhất.
        + PostgreSQL thiên về: Database nhiều tính năng, mạnh về dữ liệu phức tạp và khả năng mở rộng chức năng.
        + PostgreSQL hỗ trợ kiểu dữ liệu rất phong phú.
        + PostgreSQL rất mạnh về SQL phức tạp
        + PostgreSQL có tính "đúng đắn" và ràng buộc dữ liệu rất mạnh
        + PostgreSQL có hệ thống mở rộng rất mạnh

- MySQL thường được biết đến là:
    Dễ dùng, phổ biến, nhanh và phù hợp rất nhiều ứng dụng web.
```
