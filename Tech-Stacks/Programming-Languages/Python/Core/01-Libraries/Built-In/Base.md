# Directory structure
```bash
Built-In/                     # Mình dùng thư mục này để xem các thư viện có sẵn không cần tải 
├── System/                   # Mình dùng thư mục này để xem các thư viện liên quan đến hệ thống
├── Data-Type-Datastructure/  # Mình dùng thư mục này để định nghĩa kiểu dữ liệu và cấu trúc chứa dữ liệu
├── Math-Random/              # Mình dùng thư mục này để tính toán
└── Runtime/                  # Mình dùng thư mục này để tối ưu chạy chương trình, xử lý thời gian
```
