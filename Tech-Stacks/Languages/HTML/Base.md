# Directory Structure (cấu trúc cây thư mục)
```bash
HTML/            # tôi dùng thư mục này để xem kiến thức cơ bản của HTML 
├── Base.md      # tôi dùng thư mục này để xem các điều cần biết của html
└── Process.md   # tôi dùng thư mục này để xem lệnh cơ bản của HTML
```
