# Introduction
```bash
- TypeScript = JavaScript + Static Type
- TypeScript giúp:
    + bắt lỗi trước khi chạy
    + autocomplete cực mạnh
    + code dễ maintain
    + TS compile → JS
```
**Extentions VSCode**
```bash
1. TypeScript Hero
2. ESLint
3. Prettier
```
# Installation & Run
```bash
1. Cài TypeScript 
    npm install typescript
2. Init
    npx tsc --init
3. tạo file (.ts)
4. npx tsc
```
## Typescript + NodeJS
```bash
1. npm install ts-node
2. run trực tiếp
    npx ts-node index.ts
```
