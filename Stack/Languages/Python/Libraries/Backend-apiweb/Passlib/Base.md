# Introduction
```bash
- Thư viện passlib[bcrypt] là một thư viện dùng để mã hóa (hash) và xác thực mật khẩu một cách an toàn trong Python.
- passlib là thư viện hỗ trợ:
    + Hash mật khẩu
    + Xác thực mật khẩu
    + Quản lý nhiều thuật toán mã hóa
    + Tự động nâng cấp thuật toán khi cần
- Nó thường được dùng trong:
    + Web backend (FastAPI)
    + Flask
    + Django
    + Hệ thống đăng nhập / đăng ký
```
# Installation
```bash
1. pip install passlib[bcrypt]
- bcrypt — một thuật toán hash mật khẩu rất mạnh và phổ biến.
```
