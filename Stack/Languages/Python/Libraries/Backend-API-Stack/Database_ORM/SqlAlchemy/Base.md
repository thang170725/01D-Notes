# Directory Structure
```bash
SqlAlchemy/                     # mình dùng thư mục này để xem kiến thức về SqlAlchemy
├── Base.md                     # mình dùng file này để xem kiến thức cơ bản, tiện ích
├── Config_Create_General.md    # mình dùng file này để khởi tạo, cấu hình, xem những cái chung của ORM & Core
├── Core_Operations.md          # mình dùng file này để thao tác thuần
├── ORM_Mode.md                 # mình dùng file này để thao tác với ORM
└── Practices.md                # mình dùng file này để xem bài tập, code mẫu
```
