# Introduction
```bash
- Paho MQTT dùng để:
    + Kết nối tới MQTT Broker
    + Gửi dữ liệu (Publish)
        - Gửi dữ liệu nhiệt độ từ cảm biến IoT
        - Gửi trạng thái thiết bị (ON/OFF)
    + Nhận dữ liệu (Subscribe)
        - Nhận lệnh điều khiển từ server
        - Nhận dữ liệu từ thiết bị khác
- Ứng dụng thực tế
    + IoT (Internet of Things)
    + Điều khiển thiết bị từ xa
    + Smart Home
    + Giao tiếp giữa Raspberry Pi / ESP32 / Server
```
