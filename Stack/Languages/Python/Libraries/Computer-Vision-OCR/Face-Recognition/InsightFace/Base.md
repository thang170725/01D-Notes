# Introduction
```bash
- Là thư viện mã nguồn mở chuyên về nhận diện khuôn mặt (face recognition) và các tác vụ liên quan, xây dựng trên deep learning.
- InsightFace cung cấp pipeline gần như full cho bài toán face:
    + Face Detection (phát hiện khuôn mặt)
    + Face Recognition (so khớp danh tính)
    + Face Embedding (vector đặc trưng)
    + Face Alignment (căn chỉnh mặt)
    + Face Analysis: tuổi (age), giới tính (gender)
- Ứng dụng thực tế
    + Xác thực người dùng (Face Login)
    + Check-in / chấm công bằng khuôn mặt
    + Camera giám sát
    + AI app nhận diện khách hàng
    + App mobile nhận diện khuôn mặt
```
