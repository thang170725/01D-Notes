# Introduction
```bash
- PyQt5 là “cầu nối” giữa Python và Qt (một framework C++ rất mạnh để làm giao diện).
- Hiểu đơn giản:
    + Qt = engine làm giao diện (C++)
    + PyQt5 = giúp bạn dùng Qt bằng Python
- PyQt5 dùng để :
    1. Tạo cửa sổ (window)
        Ví dụ: App desktop, Tool nội bộ, Phần mềm có nút bấm, menu, form...
    2. Vẽ giao diện (GUI)
        Bạn có thể tạo: Button (nút bấm), Text input, Menu, Bảng dữ liệu, Layout phức tạp
    3. Xử lý sự kiện (event)
        Ví dụ: Click nút → chạy code, Di chuột → thay đổi UI
    4. Là nền cho thư viện khác (quan trọng với bạn)
```
