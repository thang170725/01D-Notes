# Introduction
```bash
- NodeJS là môi trường chạy JavaScript ở phía server.
- Trước đây: 
    + JavaScript chỉ chạy trong trình duyệt (Chrome, Firefox…)
    + Dùng để làm hiệu ứng web
- Sau này với NodeJS, JavaScript có thể:
    + Chạy trên máy tính
    + Xây dựng server
    + Làm backend
    + Tạo API
    + Kết nối database
    + Viết tool tự động
    + Làm ứng dụng realtime (chat, game online…)
```
# Installation & Setup & Running
```bash
1. node -v
2. npm -v
3. node app.js
    + để  chạy 1 ứng dựng nodeJs
```
