# Directory Structure
```bash
dev-notes                       # mình dùng thư mục này là second brain
├── Companies                   # mình dùng thư mục này để xem giới thiệu về các công ty công nghệ (các dịch vụ của họ)
├── Domains                     # mình dùng thư mục này để xem cách thiết kế hệ thống

├── Tech-Stacks                 # mình dùng thư mục này để xem tất cả kiến thức về lĩnh vục trong CNTT
└── Base.md                     # mình dùng thư mục này để xem tất cả kiến thức về công nghệ trong ngành CNTT
```
