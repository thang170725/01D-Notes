# Jina AI Company Introduction 
```bash
Jina AI là một công ty phát triển các công nghệ phục vụ cho AI Search và Retrieval.

Mục tiêu của Jina AI là giúp AI có thể:
    - Hiểu ý nghĩa của văn bản thay vì chỉ so khớp từ khóa.
    - Tìm kiếm tài liệu có nội dung liên quan.
    - Chuyển văn bản thành vector (embedding).
    - Xếp hạng lại kết quả tìm kiếm (reranker).
    - Thu thập nội dung web cho LLM.

Hiện nay Jina AI cung cấp khá nhiều dịch vụ như:
    - Embedding API
    - Reranker API
    - Reader API (chuyển website thành markdown)
    - DeepSearch
    - Các mô hình embedding mã nguồn mở
```
