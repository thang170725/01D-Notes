# số chẵn và số lẻ
**Công thức tổng n số lẻ đầu tiên**
```bash
s = n**2

chứng minh:
    S=(2⋅1−1)+(2⋅2−1)+⋯+(2⋅n−1)
    S=2(1+2+⋯+n)−n
    S=2*(n(n+1))/2 − n
     =n(n+1)−n
     =n**2
```
**Công thức tổng n số chẵn đầu tiên**
```bash
s = n*(n+1)

chứng minh:
    s = 2 + 4 + 6 + ... + 2n
      = 2*(1+2+...+n) = 2*(n(n+1))/2 = n*(n+1)
```
