# Directory Structure
```bash
Evaluate-Optimization               # mình dùng folder này để xem mô hình có tốt không và tìm cách làm cho nó tốt hơn
 ├── Accuracy_Optimization.md       # mình dùng file này để xem và làm cho mô hình học tốt hơn (tối ưu độ chính xác)
```
